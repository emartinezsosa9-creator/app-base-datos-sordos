# App Base de Datos de Atención a Personas Sordas

Este repositorio contiene la definición inicial del proyecto para construir una aplicación que permita mantener una base actualizada de personas sordas atendidas en una región determinada.

## Estado actual

**Fase:** planificación inicial (MVP).

### Entregables creados
- Definición funcional inicial del sistema.
- Modelo de datos base para registro de personas y su ubicación.
- Roadmap de implementación por fases.

Consulta los detalles en:
- `docs/requisitos-mvp.md`
- `docs/modelo-datos.md`
- `docs/roadmap.md`

## Objetivo del MVP

Permitir:
1. Registrar personas con datos básicos y ubicación.
2. Buscar y filtrar registros por región y tipo de discapacidad.
3. Editar y mantener actualizado cada caso.
4. Generar reportes básicos para planificación de atención.
