# Roadmap de creación

## Fase 1: Definición (completada)
- Alcance funcional inicial del MVP.
- Modelo de datos base.

## Fase 2: Backend
- API CRUD de personas.
- Endpoints de catálogos.
- Validaciones y paginación en listados.

## Fase 3: Frontend
- Formulario de registro/edición.
- Tabla de búsqueda con filtros.
- Vista de detalle por persona.

## Fase 4: Operación
- Autenticación por roles.
- Reporte CSV de registros filtrados.
- Despliegue inicial y pruebas de usuario.
